# VK Video Cleaner

Расширение, которое скрывает правую панель с рекомендациями в VK Видео, делая просмотр чище.

## ✨ Возможности
- Скрытие блока «Смотрите также»
- Плавное исчезновение блоков
- Удобный переключатель Вкл/Выкл
- Темная и светлая темы оформления

## 📥 Как установить
1. Перейди в раздел **[Releases](../../releases)** и скачай последний ZIP-архив.
2. Распакуй скачанный архив в любую удобную папку на компьютере.
3. Открой браузер и зайди в `chrome://extensions/`.
4. Включи **«Режим разработчика»** (тумблер в правом верхнем углу).
5. Нажми **«Загрузить распакованное расширение»** и выбери папку, которую ты распаковал.
6. Готово! Иконка метлы появится на панели браузера.
